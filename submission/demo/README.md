# TradingAgents 多视角 AI 投研助手｜Demo

## 快速启动

该目录包含已经构建好的单文件静态 Demo，不需要安装前端依赖。可以直接双击 `index.html` 离线打开。

如需用本地服务器打开：

```bash
cd submission/demo
python3 -m http.server 4173
```

浏览器访问 <http://localhost:4173>。

也可以运行项目开发版：

```bash
cd web
npm run dev
```

浏览器访问 <http://localhost:3000>。

## 黄金演示路径

1. 在“今日工作台”从顶部发起分析，或查看 AI 自选股和最近浏览。
2. 点击 NVDA 右侧的“查看案例”。
3. 查看 TradingAgents 分析进度、个人助手可信摘要和各角色报告。
4. 点击“追问个人助手”进入 Agent 协作室。
5. 浏览三组标记为“预置案例对话 · 非实时”的群聊：上涨驱动、是否买入与判断失效条件。
6. 查看市场、新闻、研究员、交易员、风险分析师和投资组合经理的不同观点，以及个人助手对事实、推断与未知信息的汇总。
7. 点击“继续模拟追问”中的建议问题并发送，查看多 Agent 追加回答。
8. 进入左侧任一角色的单聊窗口，单独追问该角色。
9. 打开“我的投研”，修改解释顺序、关注周期、重点和术语偏好，或关闭个性化与浏览记录授权。

## 降级路径

- 在没有本地 Python API 的分享环境中点击“开始多 Agent 分析”，界面会提示实时后端未连接；用户仍可从 AI 自选股打开预置案例完成全流程。
- 在预置案例中提出案例未覆盖的问题时，角色会明确说明证据不足，并建议返回总群或启动实时服务。
- 买卖类问题不会直接给出无条件交易指令；个人助手会要求补充持仓状态、投资周期和风险偏好。

## 真实能力

- 工作台、导航、画像设置、授权开关、报告浏览、总群与单聊交互均为真实可操作界面。
- 本地 Python API 启动且配置 DeepSeek 后，可创建真实 TradingAgents 分析任务并接收实时进度。
- 实时总群会根据问题类型选择相关专业角色，专业角色完成后再由个人助手总结。
- 用户画像上下文会传给对话 Agent，但只允许影响术语、详略、举例和信息顺序。

## 预置内容

- NVDA 案例、进度事件和角色回答是为稳定演示产品闭环准备的交互示例数据。
- 界面明确显示“预置交互案例 · 非实时”，不将示例数据冒充实时行情或真实投资建议。
- AI 自选股、最近浏览和画像初始值为演示账号数据；本次原型不包含真实用户账户。

## 已知限制

- 当前分享版没有托管 Python API，不能执行新的实时分析或任意实时聊天。
- 画像设置仅保存在当前页面状态，刷新后恢复为演示账号默认值。
- 本次 Demo 不包含登录、多用户数据隔离、消息推送和真实交易能力。
- 预置案例不能用于现实投资判断；需要用新数据重新运行 TradingAgents。

## Netlify

项目根目录 `netlify.toml` 已配置从 `web/` 构建。分享站点即使没有后端，也可以运行预置案例。DeepSeek API Key 只能配置在后端环境变量中，不能放在任何 `VITE_` 前端变量里。
